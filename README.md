# 光伏工程设计与交付管理系统

浏览器内全流程可用的分布式光伏工程设计与交付平台：勘测资料归集 → 导线法屋面建模 → 支架/配重 → 设备选型 → 组件级电气仿真 → 逐时发电量 → 收益测算 → 施工图数据与物料清单 → 勘测记录单 PDF。

**纯前端、全本地**：TypeScript + React + WebGL2 + IndexedDB，气象数据与工程文件均在浏览器本地处理，不依赖任何外部服务。

## 启动

```bash
npm install
npm run dev      # 开发服务器 http://127.0.0.1:5173
npm test         # 45 项工程算法验证测试
npm run build    # 类型检查 + 生产构建
```

## 三条精度红线及对应测试

1. **屋面面积误差 < 1%、平差与手算复核一致、配重与手算一致**
   - `tests/traverse.test.ts`：完美矩形零闭合差、平差改正数按边长比例且总和恰为负闭合差、锁定点份额摊派、面积误差 `<1%`、超限标红与可疑边。
   - `tests/windBallast.test.ts`：`wk=βgz·μs·μz·w0`、`G=1.4·wk·A/g` 逐式手算复核，配重块两端+跨中落位与总重汇总。
2. **双峰 I-V 下 MPPT 落点与全局 GMPP 偏差 ≤ 3%**
   - `tests/ivSimulation.test.ts`：3/12 组件遮挡形成双峰，全局扫描与多起点扰动观察偏差 `≤3%`；单起点 P&O 允许误锁低峰并单独列出误锁损失。
3. **勘测 PDF 尺寸表与测点逐条对应、改任意录入重出全篇一致**
   - `tests/surveyPdf.test.ts`：测点→PDF 行一一映射、FNV-1a 数据指纹随录入变化、采用值之和联动、未改数据两次导出指纹完全一致。

运行 `npm test` 可复现全部 45 项断言。

## 工程算法目录（纯函数，与 UI 解耦，可独立审计）

```

  roofGeometry.ts   起坡、平面交线（屋脊/天沟）、可利用面积
  windBallast.ts    抗风掀配重、落位、支架物料
  ivSimulation.ts   单二极管五参数拟合、旁路分段、多峰 MPPT
  electrical.ts     低温 Voc、MPPT 窗口、电缆载流量/压降
  selection.ts      选型组合、组串分路、停产相近度替代、基线偏差
  energy.ts         倾斜面辐照、逐时发电、损耗拆分、25 年衰减、清洗
  finance.ts        分时电价、静态回收期、IRR、NPV、敏感性
  surveyCheck.ts    对边差、勾股、水准闭合、重测离散度
  tmy.ts            典型气象年 CSV 本地解析
src/lib/webgl/      手写 WebGL2 渲染器与屋面场景
src/lib/db.ts       IndexedDB 持久化与 JSON 备份恢复
src/lib/pdf/        勘测记录单 PDF（pdf-lib，本地生成）
```

## 数据与隐私

所有项目、屋面、方案、勘测、气象数据保存在浏览器 IndexedDB（库名 `pv-engineering-suite`），可在设置页一键导出/导入 JSON 备份。PDF 在本地用 pdf-lib 生成，无任何网络请求。

## 已知边界

- 屋面交线裁剪基于平面多边形射线相交，复杂异形多坡屋面建议拆分坡面分别建模。
- pdf-lib 标准字体不含中文字形，PDF 默认输出数字/英文并提供 CJK 字体注入入口（设置页上传 .ttf/.otf 后原生中文）。
- 单二极管模型采用确定性网格拟合铭牌五参数，覆盖工程选型精度；极端失效工况以旁路分段近似。
